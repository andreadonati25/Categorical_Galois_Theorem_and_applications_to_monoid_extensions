# Categorical Galois Theorem and Applications to Monoid Extensions

Repository containing the LaTeX source code and compiled documents for my Master's thesis and presentation.

## Documents

* [Master's Thesis PDF](main.pdf)
* [Presentation Slides PDF](Slide.pdf)
* [Master's Thesis Summary PDF](Riassunto.pdf)

## Repository Structure

* `main.tex` - Main source file for the thesis.
* `Slide.tex` - Source file for the presentation slides.
* `chapters/` - Individual thesis chapters, preface and appendix.
* `bibliography/` - BibTeX bibliography files (`biblio.bib`, `biblio_Slide.bib`).
* `figure/` - University logo (`tesi_SCIENZE_TECNOLOGIE.jpg`).
* `Riassunto.tex` - Standalone abstract document sharing the preface text.
